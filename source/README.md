# Пакости по соседству — Godot 4.4.1

Восстановленный и переработанный проект игры Tembur Games. Четыре эпизода, сбор предметов, четыре вида пакостей, укрытия, погоня и мобильный мультитач сохранены.

## Сборка

1. Python 3 + Pillow: `python3 art/make_textures.py`.
2. Blender **4.3.2**: `blender --background --factory-startup --python art/build_assets.py`.
3. Godot **4.4.1**: `godot --headless --editor --import --quit`.
4. Откройте `project.godot`. Для Web нужен шаблон `web_nothreads_release.zip` Godot 4.4.1.
5. `godot --headless --export-release Web ../dist/index.html`.

Blender создаёт редактируемый `art/apartment_cast.blend` и `assets/models/apartment_cast.glb`. Модели, UV, фактуры и циклы движения воспроизводятся скриптом. Весь арт авторский, процедурный. `art/.gdignore` исключает рабочие Blender-файлы из экспорта Godot.

## Управление

- WASD / стрелки либо сенсорный джойстик слева.
- Касание пола или предмета: построить маршрут; джойстик отменяет автоматическое движение.
- E / пробел либо «Действие»: подобрать предмет, установить ловушку, спрятаться.
- Q либо кнопка качества: переключить детали / плавность.
- R: перезапустить эпизод; Escape: меню.
- На телефоне рекомендуется горизонтальная ориентация. При низкой частоте кадров игра автоматически уменьшает разрешение 3D и отключает динамические тени, сохраняя интерфейс и запечённое затенение.

## Проверки

`godot --headless --audio-driver Dummy --script res://tests/episode_smoke.gd`

`godot --headless --audio-driver Dummy --script res://tests/mobile_qa.gd`

`godot --audio-driver Dummy --script res://tests/visual_qa.gd`

`godot --audio-driver Dummy --script res://tests/performance_qa.gd`

Для скриншотов нужен графический дисплей (в CI используется Xvfb). `PAKOSTI_QA_DIR` задаёт папку кадров. Автоматизация проверяет прохождение четырёх эпизодов, маршруты, мультитач и изменение размеров окна. Эмуляция размера iPhone не заменяет замер на физическом iPhone / Safari.

Публикация разрешена только после успешных тестов и создания настоящих кадров Godot; workflow сохраняет кадры, логи и редактируемый Blender-проект как artifacts. Изображение-референс является художественным ориентиром, а не кадром игрового движка. Текущая графика не тождественна кинематографическому референсу.

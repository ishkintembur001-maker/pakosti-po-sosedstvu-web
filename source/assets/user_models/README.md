# Подключение оригинальных 3D-моделей

Игровая сцена `house_game.gd` поддерживает установку пяти оригинальных GLB владельца из папки `source/assets/user_models/`. На этой ветке код интеграции сохранён, но сами бинарные файлы пока **не хранятся в GitHub**: они поставляются отдельно в архиве `Pakosti_owner_GLBS_for_main_game.zip`.

Точные файлы:

- `hero_rigged.glb`: главный герой, 17 костей, 12 клипов, только `caught_react`.
- `neighbor_rigged.glb`: сосед, 17 костей, 12 клипов, только `catch`.
- `house_lower_quality.glb`: весь нижний этаж.
- `house_upper_quality.glb`: весь верхний этаж, **не срезан**.
- `house_roof_quality.glb`: крыша (по умолчанию скрыта для вида «кукольный домик»).

При наличии всех пяти GLB игра заменяет визуальные модели, **не меняя** сетку навигации, карты высот, AI, 24 миссии, управление, укрытия и лестницу. При отсутствии хотя бы одного файла используется прежний игровой набор, чтобы сборка GitHub не переставала запускаться.

Важные ограничения: автоматическое совмещение координат сканированного дома с существующими ловушками ещё не проверено в Godot. Риг и анимация автоматически подготовлены; визуальная приёмка кистей, ног и поимки остаётся обязательной. Без загрузки этого пакета в `source/assets/user_models/` основная игра продолжит показывать прежние модели. Это нативный проект Godot, Web-публикация отключена.

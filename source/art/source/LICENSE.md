# Anatomical head source

This directory contains only the unmodified “Head - Stylized” collection from Blender Studio Human Base Meshes v1.4.1.

Source archive: https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip
Publisher: Blender Studio and community contributors.
License: CC0 1.0 Universal, as stated on https://www.blender.org/download/demo-files/ (Human Base Meshes card).
License text: https://creativecommons.org/publicdomain/zero/1.0/

The source is anatomical mesh data, not a finished or rigged game character. `../replace_faces.py` creates the game's derived faces, accessories, colors and eye textures.

# «Пакости по соседству 3D» — только для телефона

Основные целевые платформы: **iOS (iPhone)** и **Android (ARM64)**. Сборки WebGL, HTML5, PWA и GitHub Pages исключены из развиваемой версии.

- Основная сцена Godot: `source/scenes/release_menu.tscn`.
- Горизонтальное положение, мультитач, виртуальный стик и действия сохранены.
- Сборка Android: `.github/workflows/house-preview.yml` создаёт **отладочный APK**, пригодный для теста на Android. Это не выпуск для Google Play: для публикации потребуется отдельная постоянная подпись и релизный AAB.
- Сборка iPhone: `.github/workflows/native-ios-project.yml` создаёт исходный проект Xcode **только при наличии реального идентификатора команды Apple**. В настройках GitHub Actions задаётся repository variable `GODOT_IOS_TEAM_ID` (10 букв/цифр). Секреты сертификатов и профилей не добавляются в GitHub. Проект Xcode не является установленным приложением.
- Для установки на iPhone нужен macOS + Xcode и настройка подписи под свой Apple ID/Team. Для распространения через TestFlight/App Store нужны соответствующие возможности Apple Developer.
- Отчёты Godot/Blender доступны как артефакты GitHub Actions; настоящие тесты FPS на iPhone отдельно необходимы.

**Важно:** удаление старого GitHub Pages workflow из этой ветки не выключает уже развёрнутую страницу на основной ветке `main`. Для полного отключения существующего публичного сайта нужно выключить GitHub Pages в настройках репозитория либо применить эти изменения к основной ветке.

Геймплей, все четыре классических эпизода, восемь испытаний и ловушки не изменены этой миграцией.
